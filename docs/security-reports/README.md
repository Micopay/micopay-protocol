# Security reports

These reports are point-in-time evidence for the mobile app, its backend, and
the current incident history. Reports that applied only to the former protocol
API were removed after that product migrated to
[MicoPay Bridge](https://github.com/Micopay/micopaybridge). A report's presence
does not mean the finding remains open.

For current risk status, verify the affected path in code and consult the
corresponding GitHub issue or pull request. New security work should state the
affected mobile or backend subsystem explicitly.
